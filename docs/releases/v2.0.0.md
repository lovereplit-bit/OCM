# OpenCode Mobile 2.0.0 — Полный реворк интерфейса

### Что нового:
- **100% Native Jetpack Compose UI**: Полный отказ от старого гибридного WebView интерфейса в пользу чистого нативного Jetpack Compose (адаптация opencode-mobile в ванильном стиле ChatGPT).
- **100% Русская локализация**: Все экраны, настройки, шторки (bottom sheets), диалоги подтверждения, туры онбординга, подсказки и системные уведомления переведены на русский язык.
- **Шрифт JetBrains Mono по умолчанию**: Встроен шрифт с полной поддержкой кириллицы, латиницы, перечёркнутым нулём (slashed zero) и моноширинным табличным выравниванием цифр.
- **Боковое меню (Drawer)**:
  - Живой мгновенный поиск по сессиям
  - Закрепление избранных диалогов (Pinned Sessions)
  - Выбор и управление проектами, артефактами и файлами
  - Интерактивный маскот cl0udly
- **Плавающий композер (Floating Composer)**:
  - Кнопка «+» для прикрепления файлов, изображений, @упоминаний и быстрых команд
  - Плавные физичные анимации нажатия кнопок (scale bounce)
  - Голосовой режим ввода в реальном времени
- **Шторка выбора моделей и агентов**:
  - Удобный выбор моделей с категориями
  - Настройка глубины размышлений (Reasoning Effort)
  - Быстрое переключение рабочих агентов
- **Мониторинг контекста и лимитов**:
  - Индикатор использования окна контекста в верхнем баре
  - Детальная статистика расхода токенов и затрат
